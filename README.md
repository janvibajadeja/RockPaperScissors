# Rock-Paper-Scissors 🎮

A Python implementation of the classic Rock-Paper-Scissors game with a modern twist — built using **Tkinter** for GUI and **SQLite** for persistent leaderboard tracking.

## ✨ Features
- Best-of-N rounds mode
- Difficulty levels: Easy, Normal, Hard
- Live scoreboard with round updates
- Replay option (“Play Again” button)
- Persistent leaderboard stored in SQLite (`leaderboard.db`)
- Player name input and top 10 leaderboard viewer
